# Light Weight · GymDiary: деплой update16 (редизайн + подписки)

Порядок важен: сначала база, потом бот, потом сайт.

## 1. Supabase → SQL Editor

Запускайте файлы из `supabase/sql/` по одному, сверху вниз. Если этап уже выполнен раньше, повторный запуск ничего не сломает.

| Файл | Что делает |
|---|---|
| `stage24_bodyweight.sql` | свой вес в упражнениях |
| `stage25_daily_report.sql` | отчёт в 00:00 и расписание бота (секрет берётся из Vault) |
| `stage26_shared_workouts.sql` | показ тренировок друзьям |
| `stage27_coach.sql` | режим тренировки и программа (`profiles.coach`) |
| `stage28_workout_times.sql` | время начала и конца тренировки, отдых по умолчанию 120 с |
| `stage29_macros.sql` | БЖУ на кг веса |
| **`stage30_subscriptions.sql`** | **новое**: тарифы, коды подписки, `redeem_promo`, цены, выключатель платного режима |

Перед `stage25` нужен один раз секрет в Vault: **Project Settings → Vault → Add new secret**. Name = `cron_secret`, Secret = то же значение, что у секрета функции `CRON_SECRET`. Значение секрета никуда в файлы не записывайте.

После `stage30` платный режим **выключен**: `paywall = off`, все функции открыты всем. Включить, когда будете готовы:

```sql
update app_texts set value = 'on' where key = 'paywall';
```

Цены в звёздах за месяц. По умолчанию Pro = 200 ⭐, Тренер = 400 ⭐ (≈ 5 $). Поменять цену:

```sql
update app_texts set value = '400' where key = 'price_trainer';
```

## 2. Бот: Edge Function `telegram-bot`

Обновлены файлы `index.ts` и `i18n.ts`. Деплой:

```
supabase functions deploy telegram-bot --no-verify-jwt
```

(или через Dashboard → Edge Functions → telegram-bot → вставить оба файла → Deploy).

- **Проверка:** напишите боту `/version` — должно быть `2026-10-11 · stars-subscriptions`.
- **Секреты функции не меняются:** `TELEGRAM_BOT_TOKEN`, `BOT_WEBHOOK_SECRET`, `CRON_SECRET`, `MINI_APP_URL`.
- **Звёзды (XTR):** в BotFather включать платежи не нужно.
- **Вебхук:** если вы ставили его с явным списком `allowed_updates`, добавьте в список `pre_checkout_query`. Без этого оплата не пройдёт. Если список не задавали, ничего делать не нужно. Проверить: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo` (откройте сами, токен никому не пересылайте).

## 4. Проверка после деплоя

1. **Нижнее меню.** Три вкладки: Календарь, Питание, Профиль.
2. **Календарь.**
   - Цвета дней: зелёный — тренировка; бледно-зелёный — шаги ≥ нормы; красный — без активности.
   - Нажатие на день открывает его тренировки с кнопкой ▶.
3. **Профиль → Настройки → Подписка.** Показаны тарифы и поле для кода.
4. **Профиль → Настройки → Админ-панель → «Коды подписки».**
   - Создайте код (тариф, дни, число активаций, количество кодов).
   - Код копируется автоматически. Активируйте его у себя в «Подписке».
5. **Тест оплаты.** Включите `paywall = on` и купите тариф. Бот пришлёт «Спасибо! Подписка активна до …», а тариф появится в профиле.

## Что включает Pro и Тренер (когда `paywall = on`)

- **Free:** дневник, календарь, шаблоны, питание, друзья, базовый прогресс.
- **Pro:**
  - пошаговый режим с подсказками и программы (без Pro кнопка ▶ запускает обычную запись тренировки);
  - советы по тренировке;
  - своё БЖУ на кг.
- **Тренер:** всё из Pro, плюс можно предлагать себя тренером подопечным.
- **Админ:** всё открыто всегда.
