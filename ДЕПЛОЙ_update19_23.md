## Как делать коды подписки
1. Откройте приложение под своим аккаунтом администратора: **Профиль → Настройки → Админ-панель**. Блок «Коды подписки» стоит первым.
2. Выберите тариф (Pro или Тренер), количество дней, сколько раз можно активировать каждый код и сколько кодов создать. По желанию добавьте заметку, кому они.
3. Нажмите «Создать». Один код сразу копируется. В списке у каждого кода есть кнопки ⧉ (копировать) и ✕ (удалить).
4. Отправьте код человеку. Он вводит его в **Профиль → Настройки → Подписка → Код подписки → Активировать**.

## Скрыто ли это от обычных пользователей
Да. Защита работает на сервере Supabase, а не только в интерфейсе:
- **Пункт «Админ-панель».** Виден только при `role = 'admin'` в профиле. Сменить себе роль пользователь не может: с этапа 23 её меняет только сервер.
- **Таблица кодов `promo_codes`.** Читать, создавать и удалять коды может только администратор (правило `is_admin()`). Обычный пользователь не увидит ни одного кода, даже если отправит запрос к базе вручную.
- **Активация кода.** Идёт через функцию `redeem_promo`. Код срабатывает, только если человек знает его точно и код ещё действует (срок и число активаций). Один человек может активировать каждый код один раз.
- **Таблица подписок `subscriptions`.** Пользователь может только читать свою строку. Записывают в неё только бот после оплаты и `redeem_promo`.

Чтобы назначить администратора, выполните в SQL Editor: `update profiles set role = 'admin' where telegram_username = 'ваш_ник';`
